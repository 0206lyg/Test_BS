# 일반 유체력의 다입자 연결 방식

`general` 모드는 입력 기하에서 계산한 두 입자 응답을 **상대 운동과 공통 strain에 대한 응답으로 축약한 뒤** 기존 LAMMPS solver에 더한다. 두 입자의 집단 운동에 대한 저항은 고립 입자 항으로 근사한다. 기하별 기준해, 배향별 Q, 보간 테이블은 입력하지 않는다.

이 연결 방식은 이 구현에서 선택한 다입자 근사이다. Kim의 두 입자 식 자체가 모든 입자 수에 대해 이 조립 방식을 보증한다는 뜻은 아니다. 완전한 다입자 multipole 산란이나 주기 Ewald 유동을 구현한 것도 아니다.

## 전체 두 입자 행렬을 그대로 합하지 않는 이유

두 입자 계산기는 `G = outer + near`라는 전체 17×17 응답을 반환한다. 이미 고립 입자 저항이 들어 있는 solver에 `G − G_isolated`를 이웃마다 그대로 더하면, 동일한 입자의 집단 이동 저항 감소가 이웃 수만큼 중복될 수 있다. 개별 두 입자 행렬이 모두 양의 정부호여도 전체 다입자 저항은 음수가 될 수 있다.

`test_general_manybody.cpp`는 이 문제를 작은 구조적 반례로 재현한다. 동일 방향의 입자 27개를 3×3×3 격자에 놓고 최근접 간격을 `h/c=0.1`로 정한다. 중심 간격은 `(2 AR+0.1, 2 AR+0.1, 2.1)c`이고 최근접 연결은 54개이다. AR2와 AR20에서 개별 두 입자 응답은 양수지만 전체 행렬을 단순 합산하면 공통 병진 운동의 소산이 음수가 된다. Lubrication은 공통 병진 운동에 저항을 만들지 않으므로 그 항을 크게 한다고 이 문제가 해결되지 않는다.

이것은 새 배향을 더 많이 검증해서 해결할 문제가 아니라 조립 방식의 문제다. 기본 `general` 경로는 아래 축약 방식을 사용한다. 전체 행렬 단순 합산은 진단용으로만 남긴다.

## 축약과 재조립

원래 행렬을 속도 `q` 12개와 strain `e` 5개로 나누면

\[
G=\begin{bmatrix}A&C\\C^T&D\end{bmatrix},\qquad
Q=\tfrac12q^TAq+q^TCe+\tfrac12e^TDe.
\]

`u=Bq`는 두 입자 사이 중점에서 정의한 상대 병진 3개와 상대 회전 3개다. `u`를 고정하고 나머지 집단 운동을 최소화하면 다음 11×11 응답을 얻는다.

\[
K=(BA^{-1}B^T)^{-1},\quad F=BA^{-1}C,
\]

\[
H(G)=\begin{bmatrix}
K&KF\\F^TK&D-C^TA^{-1}C+F^TKF
\end{bmatrix}.
\]

실제 pair 보정은 `P=diag(B,I₅)`를 사용하여

\[
\Delta G=P^T\,[H(G)-H(G_{isolated})]P
\]

로 정의한다. 고립 입자 항과 합치면 두 입자에 대해서는 원래 계산기의 축약 응답과 힘·토크가 없는 조건의 C5 응답이 보존된다. 전체 17×17 행렬의 모든 집단 운동 응답이 동일해지는 것은 아니다. 공통 병진 운동의 보정은 정확히 0이므로 그 저항은 고립 입자 저항으로 남는다.

위 보존은 같은 기하와 축약 사상을 쓰고 외부 거리 window가 1일 때의 행렬 항등식이다. Fluid gap floor, 거리 window, 고립 입자 집단 운동 근사는 각각 별도로 지정된 모델 선택이다. C5 보존은 두 입자 응답의 성질이며 정상상태 suspension 점도의 검증을 뜻하지 않는다.

## 근접 항과 원거리의 범위

근접항 계산기 자체는 Python 평가기의 접촉점·곡률·cubic 항과 strain 변환을 C++로 옮긴다. 기본 법선 `1/h` 및 포함된 logarithm 계수를 유지한다. 미확정 subleading 법선 logarithm은 기본값에서 제외하며 `derived`는 실험적 선택이다.

다입자 연결에서는 `outer + near` 전체를 축약한다. 근접식의 접촉 한계 lever와 실제 중점 lever는 `O(h)`만큼 다르므로 이 축약은 유한 간격에서 `O(h log h)` 등 비특이 항을 바꿀 수 있다. 따라서 현재 pair 계산기의 근접 행렬 전체가 유한 간격에서도 그대로 보존된다고 설명하지 않는다. 포함된 `1/h`와 `log h` 특이 계수는 근접 한계에서 유지된다. 근접식의 C1 유한 부분 연결도 명시된 모델 선택이며 출판된 exact matching 식은 아니다.

외부 유동은 힘·토크·stresslet moment까지 유지한다. 적분 해상도를 높이는 것은 이 moment 근사의 적분 오차를 줄이는 것이며 생략한 고차 moment를 복원하지 않는다. 또한 LAMMPS의 유한 interaction range 밖에서는 pair 보정이 0이 된다. 이를 무한 원거리 또는 주기적 다입자 유체역학의 정확해로 해석하지 않는다.

## 실행 중 검사와 결과

축약 보정 자체는 부정부호일 수 있으므로 기존 **전체 다입자 속도 저항 및 strain Schur complement 검사**를 유지한다. 실패 시 계산을 중단하며 고유값을 잘라서 통과시키지 않는다. 이는 현재 timestep의 선형 시스템을 풀 수 있는지 확인하는 계산 과정이며 배향 테이블 생성이나 전역 정확도 증명 요구가 아니다.

`validation_general/assembly_review.json`은 C++ 구조 검사의 실제 결과다. 이 검사는 다음을 확인한다.

- 개별 응답이 양수인 경우에도 전체 17×17 단순 합산이 실패하는 반례.
- 같은 27개 입자 구조에서 기본 축약 조립의 속도 저항과 자유 strain 응답이 양수인지.
- 두 입자 축약 응답과 C5가 행렬 오차 수준에서 보존되는지.
- 공통 병진 저항이 고립 입자 합과 같은지.

어느 배치에서나 통과한다는 증명이나 정상상태 점도 검증은 이 검사에 포함되지 않는다. 실제 suspension의 정상 점도에는 시간 적분, 접촉 이력, 충분한 strain 동안의 평균과 크기·시간간격·interaction range 민감도 확인이 추가로 필요하다.
