# Bidisperse spheroid update — 2026-10-28

현재 nearfield·IMEX 모델을 두 크기의 oblate spheroid에 확장합니다. 입자 크기는 초기 배치, 단일 입자 drag, 쌍 lubrication, rolling 길이와 겹침 진단에 일관되게 반영합니다. 이 변경에는 attraction이 포함되지 않습니다.

## 적용과 실행

기존 저장소에서 적용하고 다시 빌드합니다.

```bash
unzip -DD -o slurry_bidisperse_overlay_20261028.zip
python3 apply_bidisperse_settings.py
sbatch build_slurry_cpu.sbatch
```

ZIP에는 사용자가 편집하는 최상위 `run_slurry_cpu.sbatch`가 포함되지 않습니다. Helper는 `SIZE_DISTRIBUTION=bidisperse`, `SIZE_RATIO=1.4`와 두 설정을 전달하는 실행 인자만 추가·갱신합니다. 최초 변경 전 `run_slurry_cpu.sbatch.before_bidisperse_update`를 저장합니다. AR, φ, COUNT, 세 강성, timestep, step 수, 출력 간격, 경로와 Slurm 자원은 보존합니다. 다른 위치의 스크립트에는 `--file /path/to/run_slurry_cpu.sbatch`를 사용합니다.

저장소 예제의 COUNT는 1000, STEPS는 200000입니다. Helper가 기존 사용자의 COUNT나 STEPS를 이 값으로 바꾸지는 않습니다. 전단률 100 s⁻¹, timestep 2.5e-6 s에서 200000 step은 strain 50입니다. 빌드 완료를 확인한 뒤 `sbatch run_slurry_cpu.sbatch`로 제출합니다.

기본 강성은 법선 30, sliding·rolling 각각 24 N/m입니다. 고강성 시험은 법선 300, sliding·rolling 각각 240 N/m으로 완료했으며, 검증한 입자 수·농도·strain 범위는 아래에 명시합니다. 강성 변경에 맞춰 timestep을 자동으로 줄이는 정책은 추가하지 않습니다.

## 개수비와 입자 체적

크기비 q=1.4는 모든 축에 같은 비율로 적용합니다. 두 크기 집단은 같은 AR을 사용합니다. 따라서 개별 입자 부피비는 q³이고 AR에 의존하지 않습니다.

\[
N_s=\operatorname{round}\left(\frac{Nq^3}{1+q^3}\right),\qquad N_l=N-N_s.
\]

N=1000에서는 작은 입자 733개, 큰 입자 267개입니다. 이때 큰 입자 집단은 전체 고체 부피의 약 49.988%, 작은 집단은 약 50.012%를 차지합니다. 정수 개수 때문에 부피비의 아주 작은 차이는 남습니다.

`NOMINAL_DIAMETER_UM`은 평균 입자 체적에 대응하는 직경으로 정의합니다.

\[
\frac{1}{N}\sum_i D_i^3=D_{\rm nom}^3,\quad
s=\left(\frac{N}{N_s+N_lq^3}\right)^{1/3},\quad
D_s=sD_{\rm nom},\quad D_l=qsD_{\rm nom}.
\]

N=1000, D_nom=8 μm에서 D_s≈7.042823 μm, D_l≈9.859952 μm입니다. 각 입자의 축은

\[
a_i=\frac{D_i}{2}\mathrm{AR}^{1/3},\qquad
c_i=\frac{D_i}{2}\mathrm{AR}^{-2/3}
\]

입니다. AR을 바꿔도 크기 집단별 개수, 입자 체적, 요청한 φ는 유지됩니다. `SIZE_DISTRIBUTION=monodisperse`에서는 모든 D_i=D_nom이며 이전 단분산 크기 정의로 돌아갑니다. 크기비는 1<q≤2를 지원합니다.

## 초기 배치와 혼합

`INITIALIZATION=random`은 다음 순서로 기하학적 초기 상태를 만듭니다.

1. 희박한 seed 상자를 대략 한 구역에 16개 입자가 들어가도록 나눕니다. 각 구역에 두 크기 집단을 전체 조성에 맞춰 배분합니다.
2. 구역과 삽입 순서를 무작위화하고, 구역 안의 위치와 입자 배향을 무작위로 선택합니다. 격자점에 입자를 고정하지 않습니다.
3. 실제 두 입자의 크기를 사용하는 주기 Perram–Wertheim 검사로 seed 겹침을 배제합니다.
4. 크기비를 유지하며 두 집단을 함께 키웁니다. 각 입자의 크기·배향에 맞춘 병진·회전 FIRE 완화로 겹침을 제거합니다.
5. 실제 표면 간격을 사용하는 마지막 완화를 수행하고, 주기 이미지와 자기 이미지를 포함해 gap≥0을 인증합니다. 인증에 실패하면 실행 입력을 생성하지 않습니다.

공간 구역은 seed 생성에만 사용합니다. 성장·완화 중에는 입자가 구역을 자유롭게 이동하며, 완성된 배치를 다시 섞거나 크기를 바꾸지 않습니다. `parameters.json`의 `packing.seed_mixing`과 `packing.final_mixing`은 구역별 크기 집단의 개수를 기록합니다. 같은 seed와 설정은 재현 가능한 배치를 생성합니다.

이 과정은 초기 크기 분리나 동일 크기의 삽입 순서 편향을 줄이는 기하학적 준비입니다. 열역학적 평형, 전단 정상상태 또는 인력 네트워크의 평형화를 의미하지 않습니다. 전단 중의 물리적 재배열·분리·정렬은 별도로 관찰해야 합니다.

## 입자별·쌍별 계산

각 입자의 체적 등가 반경을 r_i=(a_i²c_i)^(1/3)로 정의합니다. 기존 공통 기준 길이는 수치 단위 변환에 쓰며 실제 입자의 크기를 대체하지 않습니다.

- **단일 입자 저항:** 각 입자의 실제 축을 사용한 spheroid 병진·회전 drag, Jeffery 회전과 stresslet입니다.
- **Lubrication:** 쌍 평균 반경 r_lub=(r_i+r_j)/2를 사용합니다. 표면 간격은 `max(actual_gap,0)+epsilon*r_lub`, 최대 표면 cutoff는 0.5*r_lub입니다. 비구형의 추가 국소 곡률 제한은 유지합니다.
- **Rolling:** 쌍 길이는 r_roll=2*r_i*r_j/(r_i+r_j)입니다. 입력 `ROLLING_STIFFNESS`의 단위는 N/m이며 각도 강성은 k_r*r_roll²입니다.
- **겹침 기준:** 각 쌍의 겹침을 두 입자 중 더 작은 최소 반축으로 나눕니다. 전체 진단은 쌍별 비율의 최댓값입니다. 기본 허용 기준은 0.05입니다.

같은 크기 쌍에서는 모든 식이 기존 단분산 식으로 환원됩니다. 서로 다른 크기의 실행은 `MOBILITY_BACKEND=nearfield`에서 지원합니다. mesh/direct 경로는 단분산 비교용이며 서로 다른 크기를 조용히 잘못 처리하지 않도록 거부합니다.

## 출력 해석

`parameters.json`의 `size_populations`에는 각 집단의 type, 개수, 크기 배율, 실제 축, 체적 등가 직경, 개별 입자 부피·질량과 전체 고체 부피 중 비율을 기록합니다. 입자 데이터와 trajectory의 type 1은 작은 입자, type 2는 큰 입자입니다. 구형·비구형 모두 실제 축은 입자 데이터에 저장됩니다.

`history.csv`에서 확인할 항목은 다음과 같습니다.

| 항목 | 의미 |
| --- | --- |
| `max_overlap_m` | 현재 위치에서 최대 겹침 깊이, m |
| `max_overlap_fraction_min_semiaxis` | 현재 위치의 쌍별 겹침/최소 반축 비율 중 최댓값 |
| `actual_endpoint_overlap_m` | 실제 다음 step 끝점에서 재계산한 최대 겹침, m |
| `actual_endpoint_max_overlap_fraction_min_semiaxis` | 끝점의 쌍별 겹침/최소 반축 비율 중 최댓값 |
| `minimum_semiaxis_m` | 전체 입자 중 가장 작은 최소 반축, m |

비율 0.05가 5%입니다. 최대 절대 겹침을 만드는 쌍과 최대 상대 겹침을 만드는 쌍이 다를 수 있으므로, bidisperse에서는 `max_overlap_m/minimum_semiaxis_m`을 기존 비율 열 대신 사용하지 않습니다. 기본 Slurm stdout의 thermo 표에는 이 비율이 포함되지 않습니다.

## 고강성 풀이와 검증

**검증 완료: 전체 빌드 및 CTest 54/54 통과.** 입력 생성 Python 검사 28/28은 컴파일한 packer를 사용했고 skip은 없습니다. 실제 N1000 배치는 733/267 조성, 총 입자 체적, 주기 표면 간격과 공간 혼합을 별도로 검사했습니다. 기존 사용자 실행 파일의 설정 보존과 helper 재실행도 확인했습니다.

아래 네 실행은 법선 300, sliding·rolling 240 N/m, 마찰계수 각각 10, 전단률 100 s⁻¹, 기존 timestep 2.5 μs에서 종료 코드 0으로 완료했습니다. 최대 겹침은 매 step의 현재 위치와 실제 끝점 진단 중 최댓값입니다.

| 입자 수 | AR | φ | 완료 strain | 최대 겹침/최소 반축 |
| --- | --- | --- | --- | --- |
| 1000 | 1 | 0.34 | 0.25 | 0.003781% |
| 1000 | 5 | 0.24 | 0.05 | 0.008489% |
| 256 | 1 | 0.34 | 1 | 0.061114% |
| 256 | 5 | 0.24 | 0.25 | 0.033090% |

모두 5% 겹침 기준을 만족했고, 기록된 solver 상대 잔차는 9.984e-8 이하였습니다. 기본 강성 30/24/24 N/m의 N1000·AR5·φ=0.24 비교 실행도 strain 0.05까지 완료했으며 최대 겹침은 0.090277%였습니다. 원자료와 실행 입력은 `validation_bidisperse_20261028/FINAL_VALIDATION.json` 및 그 하위 실행 폴더에 있습니다.

고강성에서 마찰 상태가 바뀌며 기존 Armijo 탐색이 매우 짧은 Newton 이동량을 반복 선택하는 실패를 수정했습니다. 세 번 이상 반감된 단계에만 볼록 목적함수의 방향 미분으로 이동량을 보강합니다. 기존에 받아들인 단계는 유지하고, 최대 12회의 평가 중 더 작은 목적함수 또는 기존 잔차 기준을 통과하는 후보만 선택합니다. 추가 행렬 분해는 없고 timestep, 강성, 마찰 상한, 40회 Newton 한도와 허용 오차는 바꾸지 않습니다.

실제 AR5·N1000·φ=0.24·300/240/240 N/m의 step 9 상태를 저장하여 재생했습니다. 기존 탐색은 40회에서 실패했으며, 수정 후 17회에 수렴했습니다. 기존 탐색의 한도만 늘린 기준 풀이는 41회에 수렴했고, 두 해의 상대 속도 차이는 2.28e-10입니다. 이 고정 상태의 실행 시간은 수정 후 약 1.69초, 기존 기준 풀이 약 4.98초였습니다. 반복 수와 시간은 해당 상태의 결과이며 전체 실행 가속률을 뜻하지 않습니다. 재현 자료는 `validation_bidisperse_20261028/stiffness/`에 있습니다.

동일한 N1000·AR5·φ=0.24의 200-step 비교에서, 기본 강성일 때 solver 변경 전후 시간은 약 1.327→1.424 s/step(+7.3%)였습니다. 수정 solver에서 강성을 10배 올린 실행은 2.441 s/step으로 기본 강성의 약 1.72배였습니다. 이는 동시 빌드·검증 작업이 있던 단일 스레드 측정이며 독립적인 성능 벤치마크나 HPC 예상 시간으로 해석하지 않습니다. 추가 행렬 분해는 없지만 높은 강성 자체가 반복 횟수를 늘릴 수 있습니다.

두 입자의 유한 preload 시험은 AR1/5, 법선 강성 3/30/100/300 N/m, sliding·rolling 0.8kn, timestep 2.5 μs에서 32개 IMEX 조합을 검사합니다. 수정이 작동하지 않는 매끄러운 경우에는 기존 해와 경로를 유지하는 회귀 검사도 포함합니다.

이전 nearfield 릴리스의 단분산 AR5·N500·φ=0.24·strain 0.25 결과는 이번 bidisperse 및 고강성 실행의 검증을 대신하지 않습니다. AR5·φ=0.34를 반드시 흐르는 상태로 만드는 것은 이번 검증의 통과 조건이 아닙니다. Solver 수렴, 최대 겹침 기준, 시간 이산화 오차와 정상상태 점도는 각각 따로 평가해야 합니다.

## 모델 선택의 의미

Mari의 두 크기 혼합은 전단 중 규칙적인 배열·결정화 억제가 목적이며, Singh도 반경비 1:1.4와 두 집단의 동일 고체 부피를 사용했습니다. 이 구현의 정수 개수 배분은 그 조성에 근접하면서 전체 평균 입자 체적을 정확히 유지합니다.

Bidispersity는 크기 분포를 바꾸므로 발산 농도·점도와 향후 인력 네트워크도 달라질 수 있습니다. 이전 peak가 결정화 때문이었다거나 이번 변경으로 사라진다고 가정하지 않습니다. 무질서한 slurry의 AR 추세를 비교할 때는 모든 AR과 φ에서 같은 크기비와 조성 규칙을 유지합니다. 인력으로 인한 yielding은 이번 릴리스에 포함하거나 검증하지 않았습니다.
